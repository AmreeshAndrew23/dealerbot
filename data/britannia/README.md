# Britannia sample catalogue (DRAFT)

Stand-in product list for the first dealer until the Tally connector imports the real masters.

- Product names and pack sizes are a realistic sample. **MRP, dealer prices and units per box/case
  are placeholders, not Britannia's actual figures.** Replace this file with the dealer's own price
  list (or a Tally export) before showing prices to anyone.
- `pack_units`: how many base pieces (PCS) are in each unit, e.g. `BOX=12;CASE=144`.
- `aliases`: names retailers actually type, in English, Tanglish and Tamil script. Separated by `;`.
